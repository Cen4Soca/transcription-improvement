# メディアファイル置き場（マニュアル用の実ファイル）

このフォルダに実際の音声・動画ファイルを置くと、`seed/seed-media-files.ts` が
ダミーバイトではなくそのファイルを S3 にアップロードします。マニュアル（Phase 2）の
校閲画面スクリーンショットで、実際の音声プレーヤー／動画が表示されるようになります。

ファイルが無い場合は、再生可能な最小ダミー（無音 / 空コンテナ）に自動フォールバック
するため、必須ではありません。

## 置くファイル名（この名前で保存してください）

`seed/seed-media-files.ts` の `SEED_ITEMS` が参照する固定名です。

| ファイル名 | 用途 | 推奨 |
|-----------|------|------|
| `sample-audio.mp3` | 校閲画面（音声・セッション 001） | 5〜30 秒程度の短い音声 mp3 |
| `sample-audio.wav` | 校閲画面（音声・セッション 002） | 短い wav |
| `sample-video.mp4` | 校閲画面（動画・セッション 003） | 5〜30 秒程度の短い動画 mp4 |
| `sample-audio-for-delete.mp3` | メディア削除テスト用（セッション 004） | 短い音声 mp3（`sample-audio.mp3` と同じでも可） |

## 注意

- 著作権フリー / 自作のファイルを使用してください。
- 短いファイル（数十秒以内・数 MB 以内）を推奨します。スクショ用途には十分です。
- ファイルを置いたら `cd e2e && npx tsx seed/seed-media-files.ts` を再実行すると
  実ファイルが S3 に反映されます（既存の DynamoDB レコードは上書きされます）。
- このフォルダのメディア実体は `.gitignore` 対象にしています（リポジトリにコミット
  しません）。README のみ管理されます。
